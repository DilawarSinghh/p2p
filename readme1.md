# Project documentation

The canonical, maintained documentation for this repository is in [README.md](README.md).

For a guided, visual walkthrough inside the running application, start the app and open `/project-guide`. That page explains the problem, solution, architecture at a high level, challenge-requirement mapping, reported model metrics, current limitations, and a suggested judge walkthrough.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000/project-guide](http://localhost:3000/project-guide).

The project uses synthetic benchmark data for its current demo. See the main README for setup details, implementation notes, evaluation caveats, and the distinction between demonstrated software and real-world validation still required.
